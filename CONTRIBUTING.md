# Contributing

Describe the problem or proposed change in an issue before making substantial changes. Keep pull requests focused and explain what changed and how it was checked.

## Local development

Serve the repository with `python -m http.server 8000`, then open http://localhost:8000. There is no build step.

## Suggested manual checks

- Start a new run and confirm the 3D scene loads without console errors.
- Check movement, mouse look, sprint, jump, interaction, and pause.
- Investigate evidence and try appropriate and inappropriate defenses.
- Confirm outcomes, integrity changes, and mission-history entries.
- Complete a level and confirm the next level unlocks.
- Reload after a mission boundary and check CONTINUE.
- Change audio and mouse settings and confirm persistence.
- Check the Impossible finale and victory or breach transitions when changing progression logic.

Report browser/version, reproduction steps, expected behaviour, actual behaviour, and relevant console errors. Do not include personal data in issue screenshots.
